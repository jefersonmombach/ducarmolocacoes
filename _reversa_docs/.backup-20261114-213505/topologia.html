Comunicação e Protocolos

REST / JSON (JWT): Browser ➔ Spring Boot (:8080)
JDBC (HikariCP): Spring Data JPA ➔ MySQL 5.7 (:3306)
HTTP / Jest Client: Spring Data ES ➔ Elasticsearch 5.6 (:9200)
SMTP (TLS): Spring Mail ➔ Mail Server (:587)

Riscos de Topologia Detectados

Dual-Write não-atômico: O backend sincroniza MySQL e ES na mesma transação síncrona.
Elasticsearch 5.6 EOL: Motor de busca em versão legada sem suporte de segurança.
Monólito Front + Back: SPA servida no mesmo processo executável JAR Spring Boot.
