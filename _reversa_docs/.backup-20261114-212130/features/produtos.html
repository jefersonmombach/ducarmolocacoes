Catálogo de Trajes & Vestuário

Estoque & Catálogo

Gerencia o acervo de trajes, vestimentas sociais e acessórios disponíveis para locação, mantendo preços de locação e custos de reposição.

Requisitos Funcionais Especificados 4 Requisitos
ID Requisito Prioridade Critério de Aceite
RF-PROD-01 Cadastrar traje/produto Must POST `/api/produtos` persiste dados e indexa no Elasticsearch.
RF-PROD-02 Atualizar dados do traje Must PUT `/api/produtos` atualiza preço ou descrição.
RF-PROD-03 Pesquisa textual Must GET `/api/_search/produtos?query={termo}` retorna itens correspondentes.
RF-PROD-04 Listagem paginada Must GET `/api/produtos` retorna página de produtos com `X-Total-Count`.
Regras de Negócio & Invariantes
  • `precoVenda`: Valor base monetário cobrado pela locação da peça. 🟢
  • `precoCompra`: Custo patrimonial de aquisição, utilizado para base de reposição em caso de danificação severa. 🟢
  • `ativo`: Booleano que define se o traje pode ser selecionado em novas locações. Trajes danificados ou aposentados devem ter `ativo = false`. 🟢
Critérios de Aceitação Formal (Gherkin)
Cenário: Cadastro de novo traje de gala
  Dado que o operador informa a descrição "Smoking Tradicional Preto", preço de venda R$ 250,00 e compra R$ 800,00
  Quando enviar uma requisição POST /api/produtos
  Então a resposta deve retornar 201 Created com o ID gerado
  E o produto deve constar como ativo no catálogo

Cenário: Desativação de traje danificado
  Dado que o produto ID 10 sofreu avaria permanente
  Quando enviar uma requisição PUT /api/produtos com ativo = false
  Então o produto deve ser atualizado com sucesso
  E o produto não deve ser oferecido para novas locações
