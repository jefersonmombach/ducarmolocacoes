Emissão de Contratos & PDF

Jurídico & Documentos

Mecanismo customizado de processamento e formatação de minutas jurídicas de locação de trajes, substituindo marcadores de dados dinâmicos (`TAG_*`) por valores formatados em moeda e data brasileira, além de gerar arquivos PDF para impressão física.

Requisitos Funcionais Especificados 3 Requisitos
ID Requisito Prioridade Critério de Aceite
RF-CT-01 Processar todas as tags do contrato Must Todas as ocorrências de `TAG_*` na minuta são substituídas pelos dados reais da locação.
RF-CT-02 Formatação de itens em tabela Must Gera tabela HTML com as descrições dos trajes locados.
RF-CT-03 Download do contrato em PDF Must GET `/api/locacaos/{id}/contrato` retorna status 200 OK com `Content-Type: application/pdf`.
