Operações Locais e Governança

Desktop & Banco Local

Gerenciamento da operação do sistema desktop no balcão da loja, rotinas de backup do arquivo SQLite ducarmolocacoes.db, integridade transacional e configurações da loja física.

Requisitos Funcionais Especificados 4 Requisitos
ID Requisito Prioridade Critério de Aceite
RF-ADM-01 Integridade do Banco SQLite Must Execução automática de PRAGMA foreign_keys = ON e modo WAL na inicialização.
RF-ADM-02 Backup com Cópia Simples Must Capacidade de cópia direta do arquivo ducarmolocacoes.db para pendrive ou armazenamento seguro.
RF-ADM-03 CLI Migrator Auxiliar Must Ferramenta CLI cmd/migrator para inicialização de schema, migração de dados e testes em lote.
RF-ADM-04 Registro de Logs Locais Should Gravação de logs operacionais em arquivo local sem expor endpoints web vulneráveis.
Regras de Negócio & Invariantes
  • Operação 100% Offline: Nenhum dado de clientes ou contratos é transmitido para a internet.
  • Zero Configuração de Servidor: O aplicativo não requer instalação de MySQL, Java Runtime, Docker ou Node.js.
Critérios de Aceitação Formal (Gherkin)
Cenário: Inicialização do banco com integridade referencial ativa
  Dado que a aplicação Desktop ducarmolocacoes é iniciada
  Quando a conexão SQLite é aberta pelo pacote internal/storage/sqlite
  Então o PRAGMA foreign_keys deve ser ativado com sucesso
  E o arquivo ducarmolocacoes.db opera em modo WAL
