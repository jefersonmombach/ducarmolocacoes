Gestão de Clientes & Locatários

Cadastro

Gerencia o cadastro, consulta, atualização e exclusão de locatários e responsáveis legais por contratos de locação de vestimentas, com pesquisa full-text desacoplada via Elasticsearch.

Requisitos Funcionais Especificados 6 Requisitos
ID Requisito Prioridade Critério de Aceite
RF-CLI-01 Criar novo cliente Must POST `/api/clientes` retorna 201 Created com o ID gerado; rejeita se ID já vier preenchido.
RF-CLI-02 Atualizar cliente existente Must PUT `/api/clientes` atualiza campos cadastrais; rejeita se ID vier nulo.
RF-CLI-03 Listagem paginada Must GET `/api/clientes` retorna página de clientes com cabeçalhos `X-Total-Count` e `Link`.
RF-CLI-04 Busca full-text Must GET `/api/_search/clientes?query={termo}` retorna resultados indexados pelo Elasticsearch.
RF-CLI-05 Exclusão de cliente Should DELETE `/api/clientes/{id}` remove do MySQL e do Elasticsearch.
RF-CLI-06 Ficha de medidas corporais (Evolução) Should Suporte a atributos antropométricos (busto, cintura, quadril, altura/comprimento) para alfaiataria. 🟡 [Validado para roadmap futuro]
Regras de Negócio & Invariantes
  • Cada cliente é identificado unicamente por seu ID gerado automaticamente. 🟢
  • O CPF e o RG são campos textuais que aceitam formatação brasileira padrão (`###.###.###-##` e `##.###.###-#`). 🟢
  • O cliente possui múltiplos canais de contato: telefone residencial, celular e telefone para recado. 🟢
  • Toda alteração (inclusão, alteração, remoção) no banco relacional deve ser refletida de imediato no índice do Elasticsearch. 🟢
Critérios de Aceitação Formal (Gherkin)
Cenário: Cadastro de novo cliente
  Dado que o operador preencheu os dados do cliente com nome "Mariana Souza" e CPF "123.456.789-00"
  Quando enviar uma requisição POST /api/clientes com os dados informados
  Então a resposta deve ter status 201 Created
  E o corpo da resposta deve conter o ID gerado
  E o cliente deve ser indexado no Elasticsearch

Cenário: Busca rápida de cliente por nome
  Dado que existe o cliente "Mariana Souza" cadastrado
  Quando enviar uma requisição GET /api/_search/clientes?query=Mariana
  Então a resposta deve retornar status 200 OK
  E a lista retornada deve incluir o cadastro de "Mariana Souza"
