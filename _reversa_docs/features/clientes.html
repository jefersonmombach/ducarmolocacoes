Gestão de Clientes e Locatários

Cadastro & Busca FTS5

Gerencia o cadastro completo de locatários e responsáveis contratuais com validação estrita de CPF, múltiplos telefones de contato e pesquisa full-text instantânea em SQLite FTS5 integrada à interface desktop Gio UI.

Requisitos Funcionais Especificados 5 Requisitos
ID Requisito Prioridade Critério de Aceite
RF-CLI-01 Cadastro com Validação de CPF Must Formulário desktop valida algoritmo de dígitos verificadores de CPF e formatação brasileira padrão.
RF-CLI-02 Busca Instantânea Local (FTS5) Must Tabela virtual SQLite FTS5 permite busca em tempo real por nome, CPF ou telefone com latência < 5ms.
RF-CLI-03 Múltiplos Canais de Contato Must Armazenamento de telefone residencial, celular e telefone para recados na mesma entidade.
RF-CLI-04 Histórico Consolidado de Locações Should Visualização do histórico de aluguéis celebrados pelo cliente diretamente na tela.
RF-CLI-05 Controle de Inadimplência Should Sinalização visual imediata caso o cliente possua pendências em contratos anteriores.
Regras de Negócio & Invariantes
  • Unicidade de Identificação: Cada cliente possui ID primário autoincrementado e chave de CPF validada.
  • Espelhamento FTS5 Transacional: O índice de busca textual local é atualizado deterministicamente na mesma transação SQLite, sem dual-write frágil.
  • Sanitização de Documentos: Máscaras de formatação são aplicadas visualmente mantendo os dados normalizados no banco.
Critérios de Aceitação Formal (Gherkin)
Cenário: Busca instantânea de cliente por fragmento de CPF
  Dado que o cliente "Carlos Drummond" possui CPF "123.456.789-00" cadastrado
  Quando o operador digita "45678" na barra de busca do ClientePage
  Então o índice SQLite FTS5 retorna o registro correspondente em menos de 5ms
  E os dados de contato do cliente são preenchidos no painel lateral
